# 🏠 Sonipat Retreat Centre — Accommodation Management App

A modern, mobile-friendly web application for managing room allotments, guest registration, and occupancy tracking at Sonipat Retreat Centre, Nangal Khurd.

## ✨ Features

- **Programme Registration** — Register new programmes with centre details, arrival times, and contact info
- **Room Allotment** — Visual room map with drag-and-drop style allocation for multiple categories (BK/NBK)
- **Niwasi Management** — Track permanent residents (Brothers, Sisters, Senior Teachers) with present/absent toggles
- **Dashboard Summary** — Real-time stats for Total, Guests, Sevadharis, Niwasis, and NBK occupants
- **Accommodation Report** — Auto-generated allotment report with WhatsApp sharing
- **WhatsApp Integration** — Share occupancy summaries directly via WhatsApp
- **Offline Ready** — Pure HTML/CSS/JS, no server needed

## 📱 Usage

1. Open `index.html` in any browser
2. Register a programme from the home screen
3. Add occupants and allot rooms
4. Track niwasi attendance with toggle switches
5. Share reports via WhatsApp

## 🛠 Tech Stack

- **HTML5** — Semantic structure
- **CSS3** — Glassmorphism, animations, responsive design
- **Vanilla JavaScript** — No frameworks, no dependencies
